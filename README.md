# 畅畅宝宝，今天也要多喝水

一个纯静态、无需登录的喝水打卡网页。喝水记录只保存在当前浏览器中，支持导出和导入备份，并可通过 PWA 安装到手机桌面。

## 本地预览

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 九天目标

第 1 至 3 天：1000 ml  
第 4 天：1250 ml  
第 5 天：1500 ml  
第 6 天：1625 ml  
第 7 天：1750 ml  
第 8 天：1875 ml  
第 9 天：2000 ml

达标后会解锁对应剧情；当天超出目标的水量仍计入总喝水量，但不会越过当天剧情上限。
